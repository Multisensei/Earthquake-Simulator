Earthquake Simulator

This repository contains an updated version of an earthquake simulation project—one of two projects I previously developed using CopperCube 6. After a year, I identified several shortcomings and unnecessary elements in the original project; this version addresses those issues and enhances the overall experience.

As in the original version, the simulation begins inside a building; however, this updated version includes the following changes:

• One of the lakes has been removed.

• Leafless trees have been removed.

• The number of trees has been increased, and their placement has been reorganized.

• Invisible walls have been added to prevent falling off the map.

• The text "Escape the earthquake" has been replaced with "Leave the house!"

Key Features: Physics-based structural shaking, "Drop, Cover, and Hold On" educational mechanics, and hazard detection.

Game Engine: CopperCube 6 (3D Game Engine) 
Target Platforms: Windows Desktop (.exe) 
Language: English has been added alongside Turkish to ensure global accessibility.
